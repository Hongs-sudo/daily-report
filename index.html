기기 간 동기화

PC · 아이패드 · 휴대폰이 같은 기록을 쓰게 합니다. 어느 기기에서 저장하든 다른 기기를 열면 자동으로 맞춰집니다.
처음 연결하는 방법 (10분)
1. 기록을 담을 비공개 저장소 만들기
깃허브에서 ＋ → New repository 를 누르고, 이름을 daily-report-data 로 넣습니다. 이번에는 반드시 Private 을 고르고 Create repository 를 누릅니다. 앱을 올려둔 저장소와는 다른 저장소여야 합니다. 이 저장소는 나만 볼 수 있어 학생 정보가 안전합니다.

2. 접근 토큰 만들기
오른쪽 위 내 사진 → Settings → 왼쪽 맨 아래 Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
· Token name: 아무 이름 (예: daily-report)
· Expiration: No expiration 또는 1년
· Repository access: Only select repositories → 방금 만든 daily-report-data 선택
· Permissions → Repository permissions → Contents 를 Read and write 로
· 맨 아래 Generate token → 나온 긴 글자를 복사
이 글자는 그 화면을 벗어나면 다시 볼 수 없으니 바로 복사해 두세요.

3. 앱에 넣기
위 칸에 아이디/daily-report-data 와 복사한 토큰을 넣고 연결하기 를 누릅니다. 다른 기기에서도 같은 두 가지를 똑같이 넣으면 연결됩니다.

알아두실 점
· 토큰은 각 기기 안에만 저장되고, 백업 파일에는 들어가지 않습니다.
· 두 기기에서 같은 학생의 같은 날짜를 동시에 고치면 나중에 저장한 쪽이 남습니다.
· 한쪽에서 지운 기록은 다른 기기에서도 지워집니다.

클라우드 폴더에 저장

구글 드라이브·원드라이브·아이클라우드 같은 동기화 폴더를 연결하면, 저장할 때마다 그 폴더의 데이터 파일에 기록되고 클라우드에도 자동으로 올라갑니다. 브라우저 캐시를 지워도, 컴퓨터가 고장 나도 기록은 남습니다. 폴더 안에는 날짜별 백업본도 함께 쌓입니다.
폴더 없이 파일 하나만 쓰려면:
동기화 폴더는 어디에 있나요?
먼저 구글 드라이브(데스크톱용) 또는 원드라이브 프로그램이 컴퓨터에 설치되어 있어야 합니다. 설치하면 내 컴퓨터 안에 폴더가 하나 생기고, 그 안에 넣은 파일이 자동으로 클라우드에 올라갑니다.
· 윈도우 원드라이브 — C:\사용자\(내 이름)\OneDrive
· 윈도우 구글 드라이브 — 내 PC → Google Drive(G:) → 내 드라이브
· 맥 아이클라우드 — Finder 사이드바의 iCloud Drive
그 안에 데일리리포트 같은 폴더를 하나 만들어 두고, 위의 “클라우드 폴더 연결”에서 그 폴더를 골라주세요.

백업 파일 받기

다른 컴퓨터로 옮기거나, 특정 시점의 기록을 따로 보관하고 싶을 때 사용하세요. 폴더를 연결하지 않았다면 기록이 이 브라우저 안에만 남으므로 주기적으로 받아두시는 것이 좋습니다.
